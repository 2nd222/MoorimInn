# MoorimInn
무림 객잔 프로젝트

이 Git 프로젝트는 무림 객잔 프로젝트의 전체 코드 파일만을 옮겨 Public으로 확인 할 수 있도록 만든 프로젝트입니다.

유건호

  담당 업무 :
	
    1. 시스템 코드 및 전체 Game Flow 구현
    2. 스토리 데이터 및 스토리 재생 UI 화면 구현
    3. 스토리 데이터에 스토리 삽입 및 화면 동작 연출 
    4. 게임 데이터 저장 및 불러오기 코드 구현 및 UI 구현
    5. 아이템, 인벤토리 데이터 및 UI 구현, 상호작용 되는 객체들(냉장고, 배식대, 플레이어블 캐릭터)의 인벤토리 세부 기능 구현
    6. 게임 내 업그레이드 시스템 및 UI 구현
    7. 담당 코드 외 다른 담당자들의 코드까지 포함한 전체 코드 디버깅 및 프로그래밍 전체 조율
		
  담당 코드 :
	
    1. 시스템 파일에서 SoundManager, PoolManager를 제외한 전체 코드
    2. 인벤토리 파일의 전체 코드
    3. 퀘스트 파일의 전체 코드
    4. NPC 파일의 전체 코드
    5. Furniture 파일의 servingslot, fridge 코드
    6. UI 파일 중
      1) Book 파일의 StoryMenu
      2) MainMenu 파일 전체
      3) Story 파일 전체
    7. _Data 파일 중
      1) Day 파일 전체
      2) Item 파일 전체
      3) Story & Dialogue 파일 전체
      4) Upgrade 파일 전체
      5) RestaurantEconomy 파일 전체
